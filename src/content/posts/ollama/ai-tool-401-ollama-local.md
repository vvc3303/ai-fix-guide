把 AI 工具切到本地模型，就是图个「不花 API 钱、数据不出本机」。结果切换后一调用就报 `401 Unauthorized`，卡了好一阵。

## 报错现象

本地 AI 工具（各类桌面 AI 客户端）里，已经把模型切换为 Ollama 本地模型，但实际调用时接口依然返回：

```text
401 Unauthorized
```

## 原因分析

切到 Ollama 时**只改了模型名，没清掉旧的云端密钥配置**。工具实际仍拿着之前填的 OpenAI 云端 API Key 去认证，而那个密钥早已过期或填错，于是返回 401。

一句话：**模型切换了，鉴权配置还是旧的。**

## 解决步骤

1. **清空本地缓存配置**：在工具本身的配置目录里，删掉旧的云端 API 密钥、缓存凭证文件。
2. **完整重走本地模型配置流程**：不要图省事只改模型名，从「添加服务商」这一步开始重新配置。
3. **全程跳过所有云端 API 密钥填写项**：本地模型（Ollama）走 `http://localhost:11434`，不需要任何云端 Key，遇到「API Key / Secret」输入框就跳过。

配置完成后重启工具，再次调用本地模型。

## 效果验证

- 调用本地模型不再返回 401
- 工具里能看到请求实际发往 `localhost:11434`
- 断网情况下本地模型仍能正常对话（云上密钥不会影响）

## 排错速查表

| 现象 | 检查点 |
|------|--------|
| 401 持续出现 | 是否还有残留云端 Key 未清 |
| 本地模型无响应 | Ollama 服务是否在跑：`ollama ps` |
| 端口不通 | 看 `ollama serve` 是否监听 11434 |

> 核心经验：**切换本地模型 = 把鉴权配置一并切换**。只改模型名、不清密钥，是最容易踩的坑。
