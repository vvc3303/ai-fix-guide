报表饼图不是统计为 0，就是重复统计，要不就是过滤条件一写就报语法错。查下来往往不是图表问题，是**过滤表达式和字段匹配**的问题。

## 报错现象

- 报表**饼图预览异常**
- 统计结果**重复**（同一数据算了多遍）
- 过滤条件**语法报错**
- 统计结果为 **0**，图表无法渲染

## 原因分析

常见三连：

1. **单元格过滤表达式缺少引号**：比如 `=状态:完成` 没加引号，平台当成变量去解析，直接报错或取不到值
2. **字段名称匹配不一致**：表达式里写的字段名和数据库里的实际字段对不上，统计不到数据 = 0
3. **重复统计**：数据集/过滤器加了多个相同的统计口径，或数据源关联关系没理清

## 解决步骤

1. **核对数据库原始字段值格式**：先看库里这个字段到底存的是什么（数字、文本、枚举），别拿猜的字段名写表达式。
2. **修正表达式语法**：文本值必须加引号：

```text
# 错误：文本值没加引号
过滤: 状态 = 完成

# 正确：文本值加引号
过滤: 状态 = "完成"
```

3. **优先使用独立 SQL 数据集做聚合**，把统计逻辑收敛在 SQL 里：

```sql
SELECT status, COUNT(*) AS cnt
FROM business_model
WHERE status = '完成'
GROUP BY status
```

再把 SQL 结果集绑到饼图，避免在报表层叠加多层过滤导致的重复统计。

## 效果验证

- 饼图正常渲染，分区比例正确
- 统计结果不再为 0、不重复
- 过滤条件不再报语法错误

## 排错速查表

| 现象 | 处理 |
|------|------|
| 统计为 0 | 核对字段名与值格式 |
| 语法报错 | 文本值加引号 |
| 重复统计 | 用独立 SQL 数据集聚合 |

> 核心经验：**报表 90% 的「统计不对」，根子在字段和表达式，不在图表**。先对数据，再调图。
